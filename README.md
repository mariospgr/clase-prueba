# Formulario de Contacto con CRUD y API de Países

Proyecto de evaluación que implementa un formulario de contacto con operaciones CRUD en LocalStorage y consumo de la API REST Countries.

## Características Principales

✅ **CRUD Completo** en LocalStorage  
✅ Validación de **formato de email**  
✅ Consumo de la API **[REST Countries](https://restcountries.com/)**  
✅ Listado, edición y eliminación de contactos  
✅ Diseño responsive con **Bootstrap**  
✅ Uso de **jQuery** para manejo del DOM  

## Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- [Bootstrap 5](https://getbootstrap.com/)
- [jQuery 3.6](https://jquery.com/)
- [REST Countries API](https://restcountries.com/v3.1/lang/spanish)

## Requisitos Cumplidos

- [x] Formulario con campos: Nombre, Teléfono, Email, País, Comentarios  
- [x] Validación de campo de email  
- [x] Almacenamiento en LocalStorage  
- [x] Listar, editar y eliminar registros  
- [x] Consumo de API para obtener países hispanohablantes  
- [x] Mostrar nombre oficial del país seleccionado
